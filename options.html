How it works

Open a saved site and press Ctrl + Shift + 9 (Mac: ⌘ + Shift + 9) to purge its entire Pull Zone. Edit the shortcut at chrome://extensions/shortcuts. Clicking the extension offers both full-zone and current-URL purges.

Full-zone purges can temporarily increase requests to your origin while the cache refills. The shortcut only works on domains you've configured; it does not purge unmatched sites.

For safety, Bunny Purge does not sync your API keys between browsers or send them anywhere except the official api.bunny.net API when you purge. Anyone with access to your unlocked Chrome profile or extension storage may still access stored keys.
